# Figma Design Workflow

## For Designers

If a user asks about design, Figma, creating screens, UI, or the design workflow:
1. Read `.claude/templates/figma-designers.md` first — it is the designer's entry point
2. Run `/design-workflow status` to check their setup state
3. If setup is incomplete, guide them through `figma-designers.md` → One-time setup steps in order
4. Entry command for all design work: `/design-workflow <subcommand>`
